# План разработки Lumen

Lumen — приложение, которое озвучивает текстовые книги нейроголосом (Qwen3-TTS) чисто, выразительно и с интонацией. Работает на Mac, iPhone/iPad, Windows и Android, написано на Flutter (Dart).

Этапы идут по порядку, у каждого своя задача на GitHub. Этап закрыт, когда его PR смёржен и строки о готовых функциях попали в [FEATURES.md](FEATURES.md).

## Решения, которые уже приняты

- **Flutter / Dart**, одна кодовая база на четыре системы (26.11.2026).
- **Один диктор на всю книгу.** Персонажи различаются только интонацией, отдельных голосов у них нет (26.11.2026).
- **Фоновая музыка** под голосом диктора — обязательная функция.
- **Дизайн «Графит»**: стекло, чёрный / серый / белый, цветные обложки, янтарная подсветка слова. Подробно в [DESIGN.md](DESIGN.md).
- **Сервер голоса не всегда включён.** В интерфейсе нигде нет слова «ПК», только «сервер». Приложение спокойно переживает выключенный сервер и отсутствие сети.
- Из Lumen_exemple берём только иконку и механику озвучки; код на Swift переписывается на Dart. Что именно и какие подвохи — в [PORTING.md](PORTING.md).
- Сервер голоса живёт в отдельном репозитории [lumen-voice-server](https://github.com/BradD06/lumen-voice-server).

| # | Этап | Что получится в приложении | Задача |
|---|---|---|---|
| 0 | Основа проекта | Пустое приложение «Графит» с иконкой и пятью вкладками запускается на всех четырёх системах; GitHub сам проверяет сборку и тесты | [#1](https://github.com/BradD06/Lumen/issues/1) |
| 1 | Ядро озвучки на Dart | Текст книги делится на фразы и абзацы с разгоном, приложение говорит с сервером голоса, фразы кешируются, время слов считается по звуку; всё под тестами | [#2](https://github.com/BradD06/Lumen/issues/2) |
| 2 | Импорт книг и хранилище | Добавить книгу EPUB, FB2 или TXT; книга разбирается на главы и абзацы и сохраняется в базе | [#3](https://github.com/BradD06/Lumen/issues/3) |
| 3 | Плеер | Книга играет в фоне и на экране блокировки, скорость до 3×, назад / вперёд, главы, таймер сна, мини-плеер; системный голос как запасной | [#4](https://github.com/BradD06/Lumen/issues/4) |
| 4 | Голос Lumen с сервера | Плеер читает голосом с сервера: первая фраза быстро, дальше абзацами; выбор голоса диктора; окна «Сервер не отвечает» и «Нет интернета», голос сам возвращается | [#5](https://github.com/BradD06/Lumen/issues/5) |
| 5 | Текст с подсветкой | Текст книги под плеером, текущее слово подсвечено янтарём, «Вид текста» (размер, шрифт, интервал) | [#6](https://github.com/BradD06/Lumen/issues/6) |
| 6 | Фоновая музыка | Спокойная музыка под голосом: выбор трека, громкость, приглушение на репликах | [#7](https://github.com/BradD06/Lumen/issues/7) |
| 7 | Главная, библиотека, место | Главная с «Слушаю сейчас», библиотека с обложками и поиском, место прослушивания и статистика | [#8](https://github.com/BradD06/Lumen/issues/8) |

| 11 | Аккаунт, синхронизация, облачный сервер | Вход, место и книги на всех устройствах, облачная очередь озвучки для пользователей без своего сервера | [#12](https://github.com/BradD06/Lumen/issues/12) |
