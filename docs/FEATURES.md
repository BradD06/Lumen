## Как устроен код

Приложение — Flutter-проект в корне (`lib/` — экраны), логика — в отдельных пакетах `packages/` (Dart workspace, один `flutter pub get` в корне). Зависимости только вниз, это проверяет `test/layers_test.dart`:

```
экраны (lib/) → lumen_player → lumen_voice → lumen_core
              → lumen_storage → lumen_core
              → lumen_import  → lumen_core
```

| Пакет | Что там | Сейчас |
|---|---|---|
| `lumen_core` | Модели и чистая логика, ни от чего не зависит | `Book` (один диктор: `narratorVoiceId`; `coverPath`, `addedAt`, `sourceName`), `Chapter` (постоянный `id` = `<книга>/<номер>`, `index`, чистый `text`, абзацы `paragraphs` — места в тексте, абзацы разделены `\n\n`; `paragraphTexts`; `Chapter.fromParagraphs`; `images` — `ChapterImage`: перед каким абзацем стоит картинка и её файл), `Line` (кусок текста с `speaker` и `emotion`; голос один, персонажи различаются интонацией), `Emotion`, `TextRange` (места в UTF-16) |
| `lumen_voice` | Озвучка: сервер голоса, фразы, кеш, время слов | `ServerLink`, `ServerState`, `VoiceServer` + `VoiceError`, `VoiceServerSettings` (`SecretStore`), `SpeechText` (фразы и разгон), `SpeechTiming` / `SpeechAlignment` (время слов), `PhraseCache`, `PhraseQueue`, `NarrationText` / `SpokenPart` / `PlaceKeeper`. Зависит от `http`, `crypto` |
| `lumen_storage` | Хранилище книг | `BookStore` (список без глав, книга целиком, обложки) и две реализации: `SqliteBookStore` (на устройстве: таблицы `book`, `chapter`, `paragraph`, `line`; у абзаца и реплики есть «кто говорит» и «чувство»; миграции только добавляются в конец `_migrations`, номер в `PRAGMA user_version`) и `MemoryBookStore` (тесты) |
| `lumen_import` | Разбор книг, без Flutter | `importBook(имя файла, байты)` → `ImportedBook` (сведения, главы, обложка, иллюстрации `images`) → `toBook(id)`; `parsePlainText` для вставленного текста; `buildPdfBook` (строки страниц PDF → главы и абзацы); `ImportException` с понятным текстом по-русски. DOCX — позже |
| `lumen_player` | Плеер: голос и фоновая музыка — две дорожки | `AudioMix` (громкость музыки, приглушение под голосом). Плеер — этап 3, музыка — этап 6 |

Проверить у себя: `flutter test` (приложение) и `dart test` в папке пакета. CI держит Flutter 3.50.1 (`FLUTTER_VERSION` в `ci.yml`).
