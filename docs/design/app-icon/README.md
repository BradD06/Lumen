# Иконка приложения

Вариант «Тихий закат» (1б): солнце садится за горизонт, под ним строки-отражения.

- `lumen-icon-ios.svg` — квадрат без скругления, iOS сама обрезает углы.
- `lumen-icon-mac.svg` — макет macOS: тело иконки 824×824 в холсте 1024 с тенью.

Готовые PNG лежат в `App/Assets.xcassets/AppIcon.appiconset`. Чтобы перерисовать,
откройте SVG в браузере или любом редакторе и экспортируйте в нужные размеры
(iOS: 1024; macOS: 16, 32, 64, 128, 256, 512, 1024).
