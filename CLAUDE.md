# Lumen: заметки для ИИ-помощника

Lumen озвучивает текстовые книги нейроголосом (Qwen3-TTS): один диктор на всю книгу, персонажи различаются интонацией, под голосом может играть фоновая музыка. Flutter (Dart): macOS, iOS, Windows, Android. Интерфейс на русском.

## Сначала прочитай

- [docs/FEATURES.md](docs/FEATURES.md) — что уже сделано и где код. Не делай заново то, что есть; новую видимую функцию добавляй туда в том же PR.
- [docs/ROADMAP.md](docs/ROADMAP.md) — этапы по порядку, одна задача на GitHub на этап.
- [docs/DESIGN.md](docs/DESIGN.md) — дизайн «Графит».
- [docs/PORTING.md](docs/PORTING.md) — что переносим из Lumen_exemple, API сервера голоса и подвохи.

## Правила владельца

- С владельцем (Брэд) говорить по-русски, просто: что изменилось в приложении, а не в git. Если ему нужно что-то сделать, дать точные шаги.
- В `main` ничего без владельца: своя ветка, PR, мёржит Брэд.
- Коммиты от имени владельца, без упоминаний ИИ (репозиторий публичный):
  `git -c user.name=BradD06 -c user.email=173235502+BradD06@users.noreply.github.com commit -m "..."`
- Отдельных голосов для персонажей нет (решение 26.11.2026).
- В интерфейсе не писать «ПК», только «сервер»: сервер голоса не всегда работает у Брэда дома.
- Ключ сервера хранить только в защищённом хранилище системы.
- Этот файл держать коротким: дизайн и подробности — в `docs/`.

## Код и проверки

- Экраны в `lib/`, логика в пакетах `packages/` (зависимости только вниз, схема в FEATURES.md). Цвета только из `Graphite`, стекло — `Glass`.
- `flutter pub get` в корне, `flutter test`, `dart test` в папке пакета, формат `dart format --line-length 100 lib test packages`. Без этих проверок CI на PR красный.
